• Before: An outage hits PostgreSQL with pool exhaustion. The agent gives generic advice: "restart the pod" or "check CPU." MTTR: 45+ minutes.
• After: The agent queries Hindsight memory, recalls Incident #412 from 3 weeks ago, matches the Kafka batch spike, and outputs the exact pg_terminate SQL command. MTTR: 90 seconds.

Vector RAG failed on log syntax noise. Hindsight’s multi-signal recall (BM25 + graph + temporal) actually understood past post-mortems.
